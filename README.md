# 드라이브 뮤직

구글 드라이브 폴더의 음악을 아이폰에서 음악 앱처럼 재생하는 개인용 앱.

- 곡 사이 끊김 없는 재생 (AVAudioEngine에 다음 곡을 이어 예약)
- 지금 곡 + 다음 곡 몇 개를 미리 받아 두고, 받다 끊기면 받은 데부터 이어받기
- 망이 돌아오거나 바뀌면 바로 다시 받기, 들은 곡은 한도 안에서 폰에 남김
- MP3 태그(제목·아티스트·앨범·표지, CP949 한글 포함)로 앨범·아티스트 분류
- 잠금화면·제어 센터·이어폰 버튼

빌드: main에 푸시하면 GitHub Actions(macOS)가 서명 없는 IPA를 만들어
`latest` 릴리스에 올리고, SideStore 소스(`source.json`)도 함께 갱신한다.
